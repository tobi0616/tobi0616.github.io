# 京阿尼 · 京都动画作品档案

一个纯静态的多页面网站作业，用 HTML / CSS / 原生 JavaScript 实现，无构建步骤、无外部依赖，离线可直接打开。

## 页面结构

| 文件 | 内容 |
| --- | --- |
| `index.html` | **首页**：京阿尼简介、四十余年历史年表、创作文化四条、2019 年纪念区块、四个分岔入口 |
| `released.html` | **已上映**：17 个系列、29 部作品。左侧真实海报，右侧上方是年份 / 形式 / 监督 / 主人公 / 故事概要 / 看点，下方是代表性 OP 与 ED（剧场版为「主题」）。支持年代筛选与关键词搜索 |
| `upcoming.html` | **未上映**：2026 年的两组新作企划——**《二十世纪电气目录》**与**《最终乐章 吹响吧！上低音号》前篇 / 后篇**，附公开日程与情报来源 |
| `staff.html` | **制作阵**：8 位创作者（石原立也、山田尚子、武本康弘、石立太一、小川太一、池田晶子、西屋太志、花田十辉），含人物照片、生卒年、代表作与简介 |
| `stories.html` | **事件与逸闻**：2019.07.18 纵火事件的经过与复出年表、粉丝所说的「京都脸」、八则逸闻，以及宇治本社的现状 |

## 使用

双击 `index.html` 即可在浏览器中打开；五个页面通过顶部导航互相链接，无需本地服务器。

## 交互说明

- **筛选**：已上映页可按 2005–2010 / 2011–2018 / 2019–2025 三个年代筛选，系列区块会自动隐藏没有结果的组。
- **搜索**：支持作品名、日文名、角色名、监督、主题歌等关键词（例如「久美子」「Lia」「上低音号」）。
- **目录**：已上映页顶部的 17 个系列目录可直接跳转。
- **动效**：滚动显现、首页花瓣、海报悬停微缩放；已适配 `prefers-reduced-motion`。
- **响应式**：≤940px 切换为抽屉式导航，≤700px 作品卡改为上下排列、筛选芯片横向滚动。

## 关于图片

- **作品海报（31 张）**：来自 AniList 的动画封面图（官方宣传视觉），本地保存为 `assets/img/works/*.jpg`，约 460×690。
- **人物照片（8 张）**：来自 AniList 人物库的公开资料图，本地保存为 `assets/img/staff/*.jpg`。
- **本社照片**：`assets/img/site/kyoani-hq.jpg`，摄影 Konomi，**公有领域**，来自 [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Kyoto_Animation_head_office_20101010.jpg)。

所有图片均下载到本地，不依赖外链；版权归原权利方所有，仅用于课程展示，不作商业用途。
如需替换为官方高清视觉，只要覆盖 `assets/img/works/<slug>.jpg` 即可，页面无需改动（容器比例为 2:3，`object-fit: cover`）。
